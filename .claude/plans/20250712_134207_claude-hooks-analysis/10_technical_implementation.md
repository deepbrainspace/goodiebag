# Technical Implementation Details

## Proposed Claude Code Hook Implementations

### 1. Intelligent PR Description Generation

**Hook Type**: PostToolUse  
**Trigger**: After `gh pr create` command  
**Purpose**: Auto-enhance PR descriptions with contextual information

#### Implementation

```json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": {
          "tool_name": "Bash",
          "command_pattern": "gh pr create.*"
        },
        "hooks": [
          {
            "type": "command",
            "command": "~/.claude/scripts/enhance-pr-description.sh",
            "continue_on_error": true
          }
        ]
      }
    ]
  }
}
```

#### Script: `enhance-pr-description.sh`

```bash
#!/bin/bash
# Enhanced PR description generator

# Read hook input
INPUT=$(cat)
COMMAND=$(echo "$INPUT" | jq -r '.tool_input.command // ""')

# Extract PR number from gh pr create output
PR_NUMBER=$(echo "$COMMAND" | grep -o 'pull/[0-9]*' | cut -d'/' -f2)

if [ -n "$PR_NUMBER" ]; then
  # Analyze affected packages
  AFFECTED_PACKAGES=$(nx affected:libs --base=main --plain)
  AFFECTED_APPS=$(nx affected:apps --base=main --plain)

  # Generate enhanced description
  ENHANCEMENT="

## Affected Packages
**Libraries**: $AFFECTED_PACKAGES
**Applications**: $AFFECTED_APPS

## Automated Analysis
- **Files changed**: $(git diff --name-only main...HEAD | wc -l)
- **Test files affected**: $(git diff --name-only main...HEAD | grep -E '\.(test|spec)\.' | wc -l)
- **Documentation updated**: $(git diff --name-only main...HEAD | grep -E '\.(md|rst)$' | wc -l)

Generated by Claude Code hooks 🤖"

  # Update PR description
  gh pr edit $PR_NUMBER --body-file <(gh pr view $PR_NUMBER --json body --jq '.body'; echo "$ENHANCEMENT")

  echo "✅ Enhanced PR #$PR_NUMBER description with automated analysis"
fi
```

### 2. Smart CI Monitoring

**Hook Type**: PostToolUse  
**Trigger**: After PR creation  
**Purpose**: Background CI monitoring with notifications

#### Implementation

```json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": {
          "tool_name": "Bash",
          "command_pattern": "gh pr create.*"
        },
        "hooks": [
          {
            "type": "command",
            "command": "~/.claude/scripts/monitor-ci.sh &",
            "continue_on_error": true
          }
        ]
      }
    ]
  }
}
```

#### Script: `monitor-ci.sh`

```bash
#!/bin/bash
# Background CI monitoring with notifications

INPUT=$(cat)
COMMAND=$(echo "$INPUT" | jq -r '.tool_input.command // ""')

# Extract PR number
PR_NUMBER=$(echo "$COMMAND" | grep -o 'pull/[0-9]*' | cut -d'/' -f2)

if [ -n "$PR_NUMBER" ]; then
  echo "🔄 Starting CI monitoring for PR #$PR_NUMBER"

  # Monitor CI status
  while true; do
    STATUS_JSON=$(gh pr view $PR_NUMBER --json statusCheckRollup 2>/dev/null)

    if [ $? -eq 0 ]; then
      PENDING=$(echo "$STATUS_JSON" | jq -r '.statusCheckRollup[] | select(.status == "QUEUED" or .status == "IN_PROGRESS" or .status == "PENDING") | .name' | wc -l)
      FAILED=$(echo "$STATUS_JSON" | jq -r '.statusCheckRollup[] | select(.conclusion == "FAILURE") | .name' | head -1)

      if [ "$PENDING" -eq 0 ]; then
        if [ -n "$FAILED" ]; then
          notify-send "CI Failed" "PR #$PR_NUMBER: $FAILED failed" --urgency=critical
        else
          notify-send "CI Complete" "PR #$PR_NUMBER: All checks passed ✅" --urgency=normal
        fi
        break
      fi
    fi

    sleep 30
  done
fi
```

### 3. Package-Aware Commit Assistance

**Hook Type**: PreToolUse  
**Trigger**: Before `git commit`  
**Purpose**: Suggest optimal commit message and validate package separation

#### Implementation

```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": {
          "tool_name": "Bash",
          "command_pattern": "git commit.*"
        },
        "hooks": [
          {
            "type": "command",
            "command": "~/.claude/scripts/commit-assistant.sh"
          }
        ]
      }
    ]
  }
}
```

#### Script: `commit-assistant.sh`

```bash
#!/bin/bash
# Commit message assistant and package validation

INPUT=$(cat)
COMMAND=$(echo "$INPUT" | jq -r '.tool_input.command // ""')

# Analyze staged changes
STAGED_FILES=$(git diff --cached --name-only)
AFFECTED_PACKAGES=$(echo "$STAGED_FILES" | grep '^packages/' | cut -d'/' -f2 | sort -u)
PACKAGE_COUNT=$(echo "$AFFECTED_PACKAGES" | grep -v '^$' | wc -l)

echo "📊 Commit Analysis:"
echo "   Staged files: $(echo "$STAGED_FILES" | wc -l)"
echo "   Affected packages: $PACKAGE_COUNT"

if [ "$PACKAGE_COUNT" -gt 1 ]; then
  echo "⚠️  WARNING: Multiple packages affected in single commit"
  echo "   Packages: $(echo "$AFFECTED_PACKAGES" | tr '\n' ', ' | sed 's/,$//')"
  echo "   Consider: Separate commits per package for better semantic versioning"
  echo ""
fi

# Suggest commit scope if single package
if [ "$PACKAGE_COUNT" -eq 1 ]; then
  PACKAGE=$(echo "$AFFECTED_PACKAGES" | head -1)
  echo "💡 Suggested scope: ($PACKAGE)"

  # Analyze change types
  if echo "$STAGED_FILES" | grep -q '\.test\.\|\.spec\.'; then
    echo "   Detected: Test changes"
  fi
  if echo "$STAGED_FILES" | grep -q '\.md$'; then
    echo "   Detected: Documentation changes"
  fi
fi

# Always allow commit to proceed
exit 0
```

### 4. Branch Management Intelligence

**Hook Type**: Stop  
**Trigger**: When Claude finishes responding  
**Purpose**: Suggest branch cleanup and main sync

#### Implementation

```json
{
  "hooks": {
    "Stop": [
      {
        "matcher": {},
        "hooks": [
          {
            "type": "command",
            "command": "~/.claude/scripts/branch-manager.sh",
            "continue_on_error": true
          }
        ]
      }
    ]
  }
}
```

#### Script: `branch-manager.sh`

```bash
#!/bin/bash
# Branch management suggestions

CURRENT_BRANCH=$(git rev-parse --abbrev-ref HEAD 2>/dev/null)

# Only suggest if not on main
if [ "$CURRENT_BRANCH" != "main" ] && [ "$CURRENT_BRANCH" != "HEAD" ]; then
  # Check if there are uncommitted changes
  if ! git diff --quiet || ! git diff --cached --quiet; then
    echo "📝 Uncommitted changes detected on branch: $CURRENT_BRANCH"
  else
    # Check if branch is ahead of main
    AHEAD=$(git rev-list --count main..$CURRENT_BRANCH 2>/dev/null || echo "0")

    if [ "$AHEAD" -gt 0 ]; then
      echo "🔄 Branch '$CURRENT_BRANCH' has $AHEAD commits ahead of main"
      echo "   Consider: Creating a PR or merging if ready"
    else
      echo "🧹 Branch '$CURRENT_BRANCH' is in sync with main"
      echo "   Consider: Switching to main and cleaning up this branch"
    fi
  fi
fi

# Check if main branch is behind origin
if [ "$CURRENT_BRANCH" = "main" ]; then
  git fetch origin main --quiet 2>/dev/null
  BEHIND=$(git rev-list --count main..origin/main 2>/dev/null || echo "0")

  if [ "$BEHIND" -gt 0 ]; then
    echo "⬇️  Main branch is $BEHIND commits behind origin/main"
    echo "   Suggestion: git pull origin main"
  fi
fi
```

### 5. NX Workflow Enhancement

**Hook Type**: PreToolUse  
**Trigger**: Before NX commands  
**Purpose**: Suggest optimal NX targets based on changes

#### Implementation

```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": {
          "tool_name": "Bash",
          "command_pattern": "nx (affected|run-many).*"
        },
        "hooks": [
          {
            "type": "command",
            "command": "~/.claude/scripts/nx-optimizer.sh"
          }
        ]
      }
    ]
  }
}
```

#### Script: `nx-optimizer.sh`

```bash
#!/bin/bash
# NX command optimization suggestions

INPUT=$(cat)
COMMAND=$(echo "$INPUT" | jq -r '.tool_input.command // ""')

# Analyze current changes
CHANGED_FILES=$(git diff --name-only main...HEAD 2>/dev/null || git diff --name-only HEAD~1...HEAD)
AFFECTED_LIBS=$(nx affected:libs --base=main --plain 2>/dev/null || echo "")
AFFECTED_APPS=$(nx affected:apps --base=main --plain 2>/dev/null || echo "")

if [ -n "$AFFECTED_LIBS" ] || [ -n "$AFFECTED_APPS" ]; then
  echo "🎯 NX Affected Analysis:"
  [ -n "$AFFECTED_LIBS" ] && echo "   Libraries: $AFFECTED_LIBS"
  [ -n "$AFFECTED_APPS" ] && echo "   Applications: $AFFECTED_APPS"

  # Suggest optimizations
  if echo "$COMMAND" | grep -q "run-many.*--all"; then
    echo "💡 Optimization: Consider using 'nx affected' instead of '--all'"
    echo "   Faster execution by testing only changed packages"
  fi
fi

# Always allow command to proceed
exit 0
```

## Installation and Configuration

### 1. Create Hook Scripts Directory

```bash
mkdir -p ~/.claude/scripts
chmod +x ~/.claude/scripts/*.sh
```

### 2. Configure Claude Code Settings

Add to `~/.claude/settings.json`:

```json
{
  "hooks": {
    // Include all hook configurations from above
  }
}
```

### 3. Test Hook Installation

```bash
# Test with dry run
export CLAUDE_HOOKS_DEBUG=1
echo '{"tool_name": "Bash", "tool_input": {"command": "git status"}}' | ~/.claude/scripts/commit-assistant.sh
```

### 4. Gradual Rollout

1. **Week 1**: Install observational hooks (branch-manager, nx-optimizer)
2. **Week 2**: Add enhancement hooks (pr-description)
3. **Week 3**: Add workflow hooks (ci-monitoring, commit-assistant)
